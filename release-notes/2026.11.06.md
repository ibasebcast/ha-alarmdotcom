# 2026.11.06

Stable maintenance update for camera streaming and trouble-condition reconciliation.

- **Camera streaming (#172, #106):** Prefer Janus when Alarm.com supplies both Janus and endToEnd connection information. Two reports confirmed that bypassing endToEnd restored streaming. Cameras that only offer endToEnd retain that path. The server-provided HD/SD stream selection and ICE configuration are preserved.
- **Camera authentication (#156):** Read the current anti-forgery cookie before API requests. A camera can share the main integration's HTTP session while retaining an older header key after session renewal, causing avoidable 403s and login attempts. This fixes that mismatch; it does not yet establish the cause of every reported login notification.
- **Trouble conditions (#173):** Remove a condition when it is absent from a successful response, rather than retaining it for three polls. This prevents missing-resource warning noise and stale or duplicate records when condition IDs change. Failed refreshes preserve existing conditions. Physical devices retain their three-refresh deletion protection.
