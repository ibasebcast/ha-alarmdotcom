Stable patch for the sign-in timeout reported in #157.

- Try the upstream identity lookup URL first, with one attempt at the alternate URL after a temporary failure or a 404.
- Give sign-in reads eight seconds per attempt and one retry for temporary failures. Authentication rejections surface immediately.
- Limit the optional dealer lookup to five seconds so setup can proceed to the required MFA check when dealer metadata is unavailable.
- Keep the detailed setup warning visible in Settings → System → Logs without enabling debug logging.
