# 2026.11.04b1

Opt-in test build for [#157](https://github.com/ibasebcast/ha-alarmdotcom/issues/157), on top of 2026.11.04b0.

- Allow up to 30 seconds for each sign-in read (was 8) and 150 seconds for the whole sign-in (was 60). The b0 test got past the login page and credentials, then timed out looking up the account identity.
- Look up the account identity, then the user profile, instead of both at once, so sign-in uses one connection at a time.
- Add per-step durations to the `Alarm.com setup` warning, for example `[loading login page 14.2s, submitting credentials 9.8s, looking up account identity 31.0s]`. The warning still omits credentials and response contents.

### What to test

Install this beta in HACS and restart Home Assistant. Try adding Alarm.com once. Report whether setup reaches the verification-code prompt or completes and loads the panel and devices. If setup fails, copy only the new `Alarm.com setup` warning from **Settings → System → Logs**, including the step durations at the end.

[Stable 2026.11.04.3](https://github.com/ibasebcast/ha-alarmdotcom/releases/tag/v2026.11.04.3) remains the rollback version.
