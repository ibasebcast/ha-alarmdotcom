## Alarm.com 2026.11.04.1

Sign-in failures during setup now identify the step that failed in **Settings → System → Logs**, with no debug logging required. The warning includes the setup attempt ID, the step, the total sign-in time, and the exception type. It omits credentials, cookies, verification codes, and response bodies.

For #157, update through HACS, restart Home Assistant, retry setup once, and share the new `Alarm.com setup` warning if it fails. This patch adds diagnostics for the sign-in timeout.
